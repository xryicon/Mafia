# Blackwater Island Prison

Blackwater Island is the prison district at `/districts/blackwater-island`. Its screens use the same dark command-panel layout, gold accents, stat strip and responsive behavior as the main dashboard. Visitors can view the island. Jailed players are routed there on protected page loads, refresh, sign-in and navigation; the shared city header checks for newly issued sentences during its normal polling and after game actions. Support, account/password access and permission-protected staff offices remain reachable.

Sentences are stored in Supabase and scoped to the current season. The server decides custody from the release timestamp, so time continues offline and no scheduled job is needed. The countdown is a display estimate; the page checks the server every five seconds and at expiry before showing release. Early release also requires a successful server response.

Free players can attempt to release an active inmate when they carry a lockpick. Lockpicks are single-use tools found through bin diving, with a 5% default find chance that uses the existing Owner bin-loot controls. Starting an attempt consumes one lockpick. The server generates a hidden lock angle and gives the rescuer five tension attempts within 90 seconds. The client displays an accessible, draggable lockpick and lock cylinder, while every result is decided and recorded by the server.

A correct tension angle releases the inmate, awards the rescuer the configured power, and adds one seasonal `breakouts` result. Blackwater Island displays the top ten breakout leaderboard along with the current player's count and rank. Five missed tension attempts or an expired 90-second timer sends the rescuer to prison until the exact release time of the inmate they tried to free. Requests are idempotent, so retries cannot consume another lockpick, duplicate power, or add another leaderboard result.

Owner panel → Blackwater Island Prison provides timed imprisonment (1 minute–7 days), a current-inmate register, early release with a required reason, and the power awarded for a successful breakout. The reward defaults to 50 and accepts values from 0 to 100,000. Ordinary players cannot issue sentences, edit custody rows, reveal hidden lock angles, or change the reward. All sentence and reward changes use the existing audit history.

Imprisonment can be issued by the Owner, a failed prison-break attempt, or a police patrol catching an active Scavenging search. Patrols use the trusted `game_private.imprison` entry point; clients cannot execute it. Walking near police does not cause arrest. No random arrests are added to jobs. Patrol sentence length is configured through Owner Economy settings, and patrol arrest records are retained separately from the current sentence.

The shared open-season gameplay guard blocks new economic and gameplay actions while jailed, including direct RPC calls. Read-only data and existing cleanup or settlement actions remain available under their original rules. Browsing a district is not a persistent free-player location; while jailed, the player's custody location is always Blackwater Island. A new season starts without old-season custody while retaining audit history.

Validation: `supabase/tests/prison.sql` checks authorization, privacy, persistence, direct job restrictions, duplicate sentencing, stale release, early release, expiry and season boundaries. `supabase/tests/prison_breaks.sql` checks lockpick loot, hidden challenge data, single-item consumption, Owner reward control, successful release, exact power and leaderboard updates, idempotency, five-miss custody and timer-expiry custody. `tests/e2e/prison.spec.ts` and `tests/e2e/prison-break.spec.ts` check routing, refresh, release, Owner controls, the lock minigame, success, both failure paths and mobile layout.
