# Resource artwork

Generated with the built-in image generation tool. Five original illustrations match Blackwater's charcoal harbor setting and copper lighting. No stock assets were used.

The game uses responsive WebP files in `public/art/resources/`: each resource has a 512px main image plus 256px and 96px variants. The shared commodity component displays them on the mine map, resource selector, site details, haul, and market screens.

Files: `public/art/resources/iron-ore.webp`, `public/art/resources/iron-ore-256.webp`, `public/art/resources/iron-ore-96.webp`.

Subject: a compact pile of raw iron ore rocks, heavy angular hematite chunks with dark gunmetal gray faces, subtle rust-red oxide veins and mineral dust. Clearly raw mined rock, not processed metal or bars.
