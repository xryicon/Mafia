# Craftable armour

Reinforced jacket: 3 silk, 2 steel; 180 seconds; 15 robbery defence.
Kevlar vest: 6 silk, 4 steel, 2 copper ingots; 360 seconds; 35 robbery defence.
Each batch produces one item at an installed crafting table. Each item requires its own blueprint, consumed once when learning the recipe for the current season. Spare blueprints and crafted armour can be traded or stored.

Blueprints are scavenging rewards. Default chances use up to 2% for the jacket and 1% for the vest from the unused nothing chance, preserving existing rewards. Owners can adjust drop chances in loot controls, recipes in crafting controls, and defence in robbery gear controls. Queue snapshots, capacity limits, learning ownership and request retries reuse the existing server rules.

Equip either in the single armour slot for robbery defence. They do not refill the separate street armour meter; no new damage absorption or repair mechanics are introduced. Crafting materials are abstract game recipes. Artwork uses lightweight dashboard-coloured SVG illustrations.
