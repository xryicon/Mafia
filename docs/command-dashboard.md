# Blackwater command dashboard

The dashboard follows the supplied September 11 reference: a broad city atlas between a player dossier and city intelligence, with territory, travel, property, market, production and event panels below. The new artwork is separate from the accessible, interactive UI.

The existing authenticated game, city, district, season and Telegram services provide all displayed economic and player information. Jobs, business acquisition and production collection use the existing server-authoritative transactions. No gameplay settings, balances, ownership, season data or database schema change in this release. Market prices are current player asking prices, labelled accordingly; no invented price movement is shown. Respect drives power and rank. Existing accounts, the six navigation destinations, online count and private Telegram system remain integrated.

The Waterfront is the current open district. Other locations in the reference are visibly unopened until configured by the Owner. Quick Travel opens the district; map selection previews its live information. Viewing a district does not invent a persistent player location. Health, energy, unimplemented crafting and fictitious timed events are not presented as live mechanics. The sidebar instead shows existing respect, inventory, operation readiness and district police heat.

Keyboard selection, zoom, panning, mobile layouts, action cooldowns, production purchases and navigation are covered by GitHub browser checks. The app is never run locally.
